## Aturan

1. Catat hanya setelah ada consent. Simpan consent di luar repo (berisi identitas).
2. Responden **anonim** (R01, R02, …). Jangan commit nama, NIM, kontak, atau dokumen skripsi asli.
3. Kutipan responden ditulis apa adanya; interpretasi dipisah dari kutipan.
4. Setiap angka yang dipakai di README/pitch wajib bisa ditelusuri ke baris di log ini.
5. Bila jumlah responden tetap kecil, **katakan kecil**: sebut sebagai penelitian eksploratif, bukan bukti kuat.
