# Glosarium

| Istilah | Arti |
|---|---|
| **ThesisTwin** | AI-powered navigation & consistency engine untuk perjalanan skripsi |
| **Digital twin (skripsi)** | Model hidup berisi struktur penelitian, feedback, keputusan, milestone, dependency |
| **Research dependency graph / Thesis knowledge graph** | Graph keterkaitan elemen penelitian (problem → … → claims) |
| **Node / Edge** | Elemen penelitian / hubungan antar elemen |
| **Alignment** | Keselarasan antar bagian (RQ ↔ objective ↔ metode ↔ analisis ↔ kesimpulan) |
| **Constraint engine** | Mesin aturan deterministik pemeriksa alignment |
| **Evidence / Provenance** | Bukti sumber (dokumen + halaman) di balik sebuah temuan |
| **Feedback-to-Action** | Pengubahan feedback pembimbing menjadi aksi terstruktur |
| **Change Impact Analysis** | Daftar bagian terdampak ketika sebuah node berubah |
| **Decision Memory** | Rekam keputusan + alasan + persetujuan + evidence |
| **Bimbingan Brief** | Ringkasan satu halaman pra-bimbingan |
| **Route Map** | Dashboard posisi, bottleneck, blocked tasks, next best action |
| **Context reconstruction cost** | Biaya mengingat ulang konteks yang tersebar |
| **Human-in-the-loop** | Keputusan akhir selalu oleh manusia |
| **Policy pack** | Paket aturan/SOP/milestone khusus kampus/prodi |
| **Unresolved dependency** | Bagian terkait yang belum diperbarui setelah revisi |
| **RQ** | Research Question |
| **SUS** | System Usability Scale |
| **RBAC** | Role-Based Access Control |
| **MVP** | Minimum Viable Product (STACK 2026: proposal Bab 1–3) |
| **STACK 2026** | Kompetisi/hackathon (handbook GDGoC ITB) tempat proposal ini diajukan |
| **Bimbingan** | Sesi konsultasi dengan dosen pembimbing |
| **Prodi / TA / SIAKAD / LMS** | Program studi / Tugas Akhir / Sistem informasi akademik / Learning management system |
