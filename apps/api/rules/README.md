# rules/

Aturan alignment sebagai **data** (YAML/JSON), bukan kode. Katalog: [docs/alignment-rules.md](../../../docs/alignment-rules.md).
Menambah aturan = tambah file data + test, tanpa mengubah engine. Tiap aturan punya `id` (`R-<TOPIK>-<NN>`), `priority`, `message` berbentuk pertanyaan/peringatan.
